# Vercel

Bu depo Vercel'e bağlıdır; `main` güncellemeleri otomatik yayınlanır.

- Root Directory: depo kökü.
- Framework Preset: Other.
- Install Command: boş.
- Build Command: boş.
- Output Directory: `.`

Bu ayarlar `vercel.json` içinde tanımlıdır. Dosyalar depo kökünden sunulur.
API anahtarı veya ortam değişkeni gerekmez.

Kaynak: https://vercel.com/docs/builds/configure-a-build
